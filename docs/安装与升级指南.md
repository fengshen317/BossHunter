# BossHunter 安装与升级指南

> 适用版本：BossHunter 2.0  
> 默认场景：本机运行 Web 工作台，并连接本机已登录的 Chrome 或 Edge

## 1. 环境要求

| 依赖 | 最低要求 | 检查命令 |
|---|---|---|
| Python | 3.11 | `python --version` |
| Node.js | 22 | `node --version` |
| PostgreSQL | 14 或更高版本 | `psql --version` |
| Chrome / Edge | 最新稳定版 | 浏览器“关于”页面 |
| Git | 推荐最新稳定版 | `git --version` |

BossHunter 当前不支持 SQLite 运行时降级。业务数据、Agent 状态和检查点都需要 PostgreSQL。

## 2. 获取代码并安装

```bash
git clone https://github.com/powerycy/BossHunter.git
cd BossHunter

# 建议使用虚拟环境
python -m venv .venv

# Windows Git Bash
source .venv/Scripts/activate

# macOS / Linux
# source .venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e .
```

只有在默认 PDF 渲染不可用、需要 `xhtml2pdf` 后备方案时，才安装可选依赖：

```bash
python -m pip install -e ".[pdf]"
```

安装后检查：

```bash
bosshunter --version
bosshunter --help
node --version
```

## 3. 准备 PostgreSQL

下面以本机 PostgreSQL 和数据库名 `bosshunter` 为例。用户名、密码和主机应替换为自己的值。

```bash
createdb -U postgres bosshunter
psql -U postgres -d bosshunter -f migrations/postgresql/001_agent_runtime.sql
psql -U postgres -d bosshunter -f migrations/postgresql/002_business_data.sql
psql -U postgres -d bosshunter -f migrations/postgresql/003_semantic_layer.sql
psql -U postgres -d bosshunter -f migrations/postgresql/004_context_memory.sql
psql -U postgres -d bosshunter -f migrations/postgresql/005_workbench_task_stage.sql
```

迁移文件必须按编号执行。若某个迁移失败，应保留完整错误信息并先解决，不要跳过编号继续运行。

## 4. 创建本地配置

```bash
cp config.example.yaml config.yaml
cp resume.example.md resume.md
```

至少修改以下内容：

1. `database.url`：填写 PostgreSQL 连接地址。
2. `profile.resume_path`：指向本人的 Markdown 简历。
3. `profile.target_roles`、`search.keywords` 和 `search.cities`。
4. `ai.provider`、`ai.model` 以及对应 API Key。
5. `throttle.daily_limit`、发送间隔和时间窗口。

连接地址示例：

```yaml
database:
  url: "postgresql+psycopg://postgres:你的密码@127.0.0.1:5432/bosshunter"
```

推荐通过环境变量传入 AI 密钥：

```bash
# Anthropic 或 Anthropic Messages 兼容接口
export ANTHROPIC_API_KEY="your-api-key"

# OpenAI 兼容接口
export OPENAI_API_KEY="your-api-key"
export OPENAI_BASE_URL="https://example.com/v1"
```

更多字段见[配置参考](配置参考.md)。`config.yaml`、`.env`、真实简历和 `data/` 已被 Git 忽略，不要强制提交。

## 5. 首次启动

Windows 推荐执行：

```bash
bosshunter start
```

也可以双击 `start-bosshunter.cmd`。该命令会启动独立的 Chrome/Edge 用户目录和 Web 工作台。首次使用时需要在打开的浏览器中手动登录招聘平台。

如果已经自行启动了支持远程调试的浏览器：

```bash
bosshunter connect
bosshunter web
```

工作台默认地址为 `http://127.0.0.1:8686`。首次正式运行前，建议先按[操作手册](操作手册.md)执行少量岗位的分步流程。

## 6. 升级

升级前先停止 CLI、Web 工作台和监测任务，并备份 PostgreSQL：

```bash
pg_dump -U postgres -d bosshunter -F c -f bosshunter-backup.dump
git status
git pull --ff-only
python -m pip install -e .
```

随后检查 `migrations/postgresql/` 是否出现新的编号文件；只执行尚未应用的迁移。前端 `dist/` 已作为仓库构建产物提交，普通使用者无需自行构建。

升级完成后执行：

```bash
bosshunter --version
bosshunter connect
bosshunter status --full
```

## 7. 卸载与数据保留

```bash
python -m pip uninstall bosshunter
```

卸载 Python 包不会自动删除 PostgreSQL 数据库、`data/`、`config.yaml` 或浏览器登录状态。如需清理这些数据，应先确认备份并手动处理；不要把真实数据提交到公开仓库。
