## 文档约定

- 命令默认从仓库根目录执行。
- Windows 示例可在 Git Bash 或终端中执行；Python 命令统一写作 `python`。
- 文档不记录真实 API Key、简历、数据库凭据、浏览器会话或内部服务地址。
- 第三方平台页面和选择器可能变化；发现文档与实际界面不一致时，请先停止自动化并提交 Issue。
