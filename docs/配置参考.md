# BossHunter 配置参考

配置文件默认位于仓库根目录的 `config.yaml`。请从 `config.example.yaml` 复制，不要直接修改并提交示例中的占位值。

## 1. 配置加载与密钥

- CLI 可通过全局参数 `--config PATH` 指定配置文件。
- AI 密钥优先从环境变量读取，也可以写入本地 `config.yaml`。
- `.env`、`config.yaml`、真实简历和 `data/` 不应进入 Git。
- Web API 返回配置时会脱敏密钥，但这不能替代本机文件权限和环境变量管理。

常用环境变量：

| 变量 | 用途 |
|---|---|
| `ANTHROPIC_API_KEY` | Anthropic 或兼容接口密钥 |
| `ANTHROPIC_AUTH_TOKEN` | 使用 Auth Token 的兼容接口 |
| `ANTHROPIC_BASE_URL` | Anthropic Messages 兼容接口地址 |
| `OPENAI_API_KEY` | OpenAI 兼容接口密钥 |
| `OPENAI_BASE_URL` | OpenAI 兼容接口地址 |
| `BOSSHUNTER_BASE_DIR` | `config.yaml` 和运行目录的基准路径 |
| `BOSSHUNTER_HOST` / `BOSSHUNTER_PORT` | 服务监听地址和端口 |
| `BOSSHUNTER_AUTH_TOKEN` | 非回环地址访问 `/api/*` 时的 Bearer Token |
| `BOSSHUNTER_S3_ACCESS_KEY` / `BOSSHUNTER_S3_SECRET_KEY` | S3/MinIO 制品存储凭据 |

## 2. `profile`：个人目标与简历

| 字段 | 说明 |
|---|---|
| `resume_path` | 本人的 Markdown 简历路径 |
| `resume_output_dir` | 定制简历输出目录 |
| `avatar_path` | 可选本地头像，仅用于 PDF 排版 |
| `target_roles` / `target_cities` | 目标岗位和城市 |
| `salary_min` / `salary_max` | 期望薪资，单位 K |
| `deal_breakers` | 对岗位名称生效的一票否决词 |
| `allow_internship` | 是否接受实习岗位 |
| `whitelist_companies` | 公司名子串白名单；命中后进入人工确认 |
| `blocked_companies` | 外包、人力或猎头公司名子串黑名单 |
| `filter_agency_jobs` | 是否根据高精度短语过滤外包/驻场岗位 |
| `extra_highlights` / `portfolio_url` | 招呼语可用的额外亮点和作品链接 |

白名单只表示跳过自动过滤并进入人工判断，不表示自动批准或自动发送。

## 3. `search` 与 `scoring`：采集和评分

| 字段 | 说明 |
|---|---|
| `search.keywords` | 搜索关键词列表 |
| `search.cities` | 搜索城市列表 |
| `search.max_pages` | 每组搜索最多翻页数 |
| `search.sort` | 排序方式，示例为 `newest` |
| `scoring.threshold` | AI 深度评分通过阈值 |
| `scoring.max_candidates` | 单次深度评分候选上限 |
| `scoring.concurrency` | 深度评分并发数；过高可能触发限流 |
| `scoring.min_registered_capital_wan` | 注册资本硬阈值；字段缺失时不据此淘汰 |

注册资本过滤依赖企业信息补全。需要时先运行 `bosshunter reenrich`。

## 4. `throttle`：发送安全限制

| 字段 | 说明 |
|---|---|
| `daily_limit` | 每日发送上限 |
| `interval_min` / `interval_max` | 两次发送之间的随机秒数范围 |
| `send_windows` | 允许发送的本地时间窗口 |
| `only_send_when_hr_online` | 仅在 HR 在线或刚活跃时发送 |
| `browse_before_greet` | 发送前是否先浏览岗位页 |
| `browse_duration_min/max` | 发送前浏览时长范围，单位秒 |
| `day_off_probability` | 随机休息日概率 |
| `send_max_retries` | 单个岗位内的临时失败重试次数 |
| `send_retry_backoff_min/max` | 岗位内重试的退避范围，单位秒 |
| `auto_recover_send_errors` | 是否让可恢复错误重新进入队列 |
| `send_error_recover_seconds` | 重新进入队列前的等待秒数 |
| `send_error_max_retries` | 队列级错误的最大恢复次数 |

人工确认、时间窗口和每日上限是安全边界。不要为了提高数量而放宽默认值，也不要把 `send --force` 当作绕过审批的方式。

## 5. `ai`：模型服务

| 字段 | 说明 |
|---|---|
| `provider` | `anthropic` 或 `openai_compatible` |
| `model` | 模型名；兼容接口会尝试匹配可用模型 |
| `api_key` / `auth_token` | 本地凭据，推荐改用环境变量 |
| `base_url` | 兼容服务 API 根地址 |
| `request_timeout` | 单次请求超时秒数 |
| `http_max_retries` | 5xx、429 和瞬时网络错误重试次数 |
| `greeting_concurrency` | 招呼语生成并发数 |
| `greeting_review_threshold` | 招呼语质量复核阈值 |
| `greeting_max_iterations` | 招呼语最大改写次数 |
| `resume_max_pages` | 定制简历目标最大页数 |

接口持续返回 401/403 时应检查凭据，不要反复重试；返回 429 时应降低并发或等待配额恢复。

## 6. `assistant` 与 `resume`

`assistant.context` 控制上下文窗口预算、输出保留、安全余量、最近历史比例和压缩批次；`assistant.memory` 控制长期记忆捕获及召回上限。除非正在诊断上下文问题，建议保留示例默认值。

`resume` 支持：

- `template`：`modern`、`executive` 或 `ats`。
- `theme_color`：PDF 主题色。
- `show_avatar`：是否在视觉简历中显示头像。
- `generate_ats_version`：是否同时生成无头像的 ATS 版本。

生成后必须人工核对事实、联系方式和排版。

## 7. `monitor`、`follow_up` 与 `dedup`

| 配置段 | 字段 | 说明 |
|---|---|---|
| `monitor` | `interval` | 持续监测间隔，单位分钟 |
| `monitor` | `chat_url` | 招聘平台聊天页地址 |
| `monitor` | `auto_reply_hr_questions` | 开启时自动发送 AI 回复；默认关闭并生成待确认建议 |
| `follow_up` | `enabled` | 是否启用超时跟进 |
| `follow_up` | `interval_hours` | 首次跟进等待小时数 |
| `follow_up` | `skip_weekends` | 是否跳过周末 |
| `dedup` | `history_file` | 本地去重历史文件 |

首次使用建议关闭自动回复和自动跟进，先观察单次监测结果。

## 8. `browser`：本地浏览器运行时

| 字段 | 说明 |
|---|---|
| `runtime` | 当前内置运行时使用 `builtin` |
| `proxy_host` / `proxy_port` | 本地 CDP 代理监听地址和端口 |
| `chrome_ports` | 浏览器远程调试端口候选列表 |
| `preferred_browser` | `auto`、`chrome` 或 `edge` |
| `executable_path` | 可选浏览器可执行文件路径 |
| `user_data_dir` | 独立浏览器用户目录 |
| `auto_start_proxy` | 是否自动启动内置代理 |
| `enable_port_guard` | 是否启用端口占用保护 |
| `site_patterns` | 是否加载站点交互模式 |

`user_data_dir` 含登录状态，属于敏感数据，禁止提交或分享。

## 9. `database`、`runtime` 与 `artifacts`

- `database.url` 必须是 `postgresql://` 或 `postgresql+psycopg://` 地址。
- `runtime.redis_url` 用于 Redis；单进程桌面运行可留空。
- `runtime.redis_required` 可要求 Redis 必须可用；多实例部署应显式启用。
- `runtime.worker_enabled` 与 `max_concurrency` 控制后台 Worker。
- `artifacts.backend` 支持 `local` 或 `s3`。
- 本地制品由 `artifacts.local_path` 指定；S3/MinIO 密钥应通过环境变量提供。

## 10. Web 暴露安全

默认只绑定 `127.0.0.1`。如果将 `BOSSHUNTER_HOST` 设置为 `0.0.0.0` 或局域网地址，服务会要求设置 `BOSSHUNTER_AUTH_TOKEN`；访问 `/api/*` 时必须携带：

```text
Authorization: Bearer <token>
```

不建议直接将工作台暴露到公网。反向代理、TLS、访问控制和日志脱敏应由部署者自行负责。
